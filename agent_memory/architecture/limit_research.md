# 打板 / 情绪 / 题材研究数据底座（AR 主线）

权威规划与验收记录：仓库根目录《牛牛AI交易助手_自主研究与打板情绪研究_规划与进度.md》。本文件只给 Agent 使用这些数据时必须遵守的边界。

## 数据分层

| 层 | 位置 | 性质 |
|---|---|---|
| 回溯日线 | `artifacts/_market_data/retro_daily/` | Baostock 回溯观察值，2019-01-02 起；research_only |
| 前瞻日线与参考 | `_market_data/daily_market/`、`_market_data/forward_reference/` | 每日收盘后快照，接在回溯数据之后 |
| 公开证据 | `_market_data/public_evidence/<source>/<day>/` | 东方财富股池、龙虎榜、板块、人气榜的收盘后归档；供应商口径，不补历史 |
| 涨停事件库 | `_limit_research/limit_events/` | 日线推算的涨跌停状态与事件；特征为 T 日收盘已知，`t1_/t2_/ret_` 是事后结果 |
| 日度情绪 | `_limit_research/market_sentiment/` | 40 个指标，T 日收盘后可用，仅用于 T+1 及以后 |
| 题材事实 | `_limit_research/theme_daily/` | 板块涨停梯队、龙头候选、持续天数；机器状态一律 UNKNOWN |
| 前瞻明细 | `_limit_research/event_details/` | 封板时间、封单、炸板次数、龙虎榜、人气；须与日线核对一致才可用 |
| 事件研究 | `_limit_research/event_studies/<family>/` | 先登记冻结规格再计算，结果不可覆盖，同族 Holm 校正 |
| 收盘复盘 | `_limit_research/daily_review/<day>/` | 事实层 / 机器状态层 / 评论层分开保存，评论只追加 |
| 可验证预测 | `_limit_research/forecasts/<target_day>/` | 开盘前记录的二元概率预测，收盘后按情绪指标判定，Brier 计分并与机器基准比较 |
| 自主研究 | `_limit_research/auto_research/` | 宿主授权的研究计划、提案队列、夜间样本内筛选与质疑清单记录；Agent 只能提案 |
| 研究结论 | `_limit_research/conclusions/` | 宿主晋级的锁定样本外确认（确认族 Holm）与每日前瞻滚动监控；状态 MONITORING/DECAYING/NOT_CONFIRMED/RETIRED |
| 盘前简报 | `_limit_research/premarket_brief/<target_day>/` | 依据前一个收盘：情绪、仍有效规律与观察名单、衰减规律、题材、已记录预测、版本化风险提示与数据缺口 |

## Agent 必须遵守

1. 先用 `get_limit_research_status` 确认覆盖日期；工具失败或数据不存在时如实说明，不凭记忆补数。
2. 研究条件只能引用 T 日特征、`mkt_` 情绪列与 `em_` 明细列；`t1_/t2_/ret_` 结果列只用于复盘描述，永远不能当作当时已知的信息或筛选条件。
3. 当日涨停价打板（`t0_limit_price`）只能用盘中买入前已知的列；`em_` 明细、情绪、收盘形态一律视为收盘后信息。
4. 涨跌停由研究制度表推算，不是官方逐日 MarketRules；东方财富股池不含 ST，且以“封板”为口径，我们的“炸板/收盘跌停”是日线口径的超集。
5. 结论只认预登记研究：显著但方向与预登记相反（`significant_opposite_direction`）不能当作支持；未登记的探索性统计只能称为观察。
6. 信号标签收益不等于可执行收益。打板结论必须看成交模型（开盘涨停买不到、一字板排不到、跌停顺延、费用滑点），排板只有保守/乐观两种情景的范围。
7. 情绪周期阈值、题材排序、通用板块名单都是版本化工程规则，不是专家规则、题材强弱判断或交易信号。
8. Agent 没有构建数据集、抓取网页、直接登记或运行研究、写 Theme Matrix 的工具；这些都由宿主或收盘后调度执行。任何输出都不得变成买卖指令。
9. 写入只有两种：`record_limit_forecast`（只能针对目录内问题、在目标交易日 09:15 前记录、同题同日一次且不可修改，概率要有工具证据和依据说明）与 `propose_auto_study`（见第 11 条）。AI Team 复核员两个工具都没有。
10. 评价预测只看记分卡：Brier 越低越好，技能分以同题同日的 250 日气候基准为参照；少于 30 条已判定预测时只能说“样本不足”。复盘评论是判断，不得写回事实层。
11. 自主研究只在宿主用 `niuniu-auto-research` 授权研究计划（≤30 天）后进行：先 `get_auto_research_status` 看范围与预算，再 `propose_auto_study` 提案。提案必须预登记方向，只能用计划允许的结果列、成交模型与数据列；夜间任务只在样本内区间运行，按质疑清单（样本量、p ≤ 0.01、方向、经济幅度、年份与单日集中度、分年稳定性、成交可行性、扣费后收益、未来函数）筛选。同一检验只运行一次，改族名或方向不能重跑，失败也消耗预算。通过筛选不是结论：确认只能由宿主晋级到锁定样本外区间，在计划唯一的确认族内做 Holm 校正。
12. 结论只看 `list_research_conclusions`：只有 `MONITORING`（已确认且前瞻监控未衰减）才能称为“仍有效的已确认规律”；`DECAYING` 表示最近 180 天效果反向、缩水一半以上或成交检查不过，不得再当作有效；确认族每多一项晋级，早先的确认都会按 Holm 重新评估。历史锁定区间可能被 Agent 在日常工具中看过，确认只是弱确认，前瞻监控才是主要检验。Agent 不能晋级或退役结论，结论也不是交易信号。
13. 盘前简报用 `get_premarket_brief`：它只汇总前一个收盘后已知的事实与机器状态；观察名单只是符合已确认规律条件的股票，不是买入建议，也不代表能成交；风险提示是阈值规则（附近 250 日分位），不是预测。简报里没有的内容不要补编。

## 每日自动化（Mac 上的收盘后调度）

15:40 股池/人气 → 15:45 板块 → 16:00 起每周成分（可续抓）→ 16:10 题材事实（输入变化即重建）→ 17:30 龙虎榜 → 18:00 DailyMarket 与前瞻参考 → 18:10 事件库与情绪重建到当天 → 18:15 前瞻明细与核对 → 18:20 收盘复盘 → 18:25 判定当日预测并为下一个工作日生成机器基准预测 → 19:00 自主研究夜间筛选（仅在有有效计划时，不超过每晚预算）→ 19:30 运行宿主晋级的确认研究并对已确认结论做前瞻监控（事件库重建后自动重算）→ 19:40 为下一个工作日生成盘前简报（复盘、结论或预测变化时重建，次日 09:15 前仍会更新）。盘中与集合竞价采集未授权（待决定事项 D-1）。
