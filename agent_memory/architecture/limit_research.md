# 打板 / 情绪 / 题材研究数据底座（AR 主线）

权威规划与验收记录：仓库根目录《牛牛AI交易助手_自主研究与打板情绪研究_规划与进度.md》。本文件只给 Agent 使用这些数据时必须遵守的边界。

## 数据分层

| 层 | 位置 | 性质 |
|---|---|---|
| 回溯日线 | `artifacts/_market_data/retro_daily/` | Baostock 回溯观察值，2019-01-02 起；research_only |
| 前瞻日线与参考 | `_market_data/daily_market/`、`_market_data/forward_reference/` | 每日收盘后快照，接在回溯数据之后 |
| 公开证据 | `_market_data/public_evidence/<source>/<day>/` | 东方财富股池、龙虎榜、板块、人气榜的收盘后归档；供应商口径，不补历史 |
| 涨停事件库 | `_limit_research/limit_events/` | 日线推算的涨跌停状态与事件；特征为 T 日收盘已知，`t1_/t2_/ret_` 是事后结果 |
| 日度情绪 | `_limit_research/market_sentiment/` | 40 个指标，T 日收盘后可用，仅用于 T+1 及以后 |
| 题材事实 | `_limit_research/theme_daily/` | 板块涨停梯队、龙头候选、持续天数；机器状态一律 UNKNOWN |
| 前瞻明细 | `_limit_research/event_details/` | 封板时间、封单、炸板次数、龙虎榜、人气；须与日线核对一致才可用 |
| 事件研究 | `_limit_research/event_studies/<family>/` | 先登记冻结规格再计算，结果不可覆盖，同族 Holm 校正 |

## Agent 必须遵守

1. 先用 `get_limit_research_status` 确认覆盖日期；工具失败或数据不存在时如实说明，不凭记忆补数。
2. 研究条件只能引用 T 日特征、`mkt_` 情绪列与 `em_` 明细列；`t1_/t2_/ret_` 结果列只用于复盘描述，永远不能当作当时已知的信息或筛选条件。
3. 当日涨停价打板（`t0_limit_price`）只能用盘中买入前已知的列；`em_` 明细、情绪、收盘形态一律视为收盘后信息。
4. 涨跌停由研究制度表推算，不是官方逐日 MarketRules；东方财富股池不含 ST，且以“封板”为口径，我们的“炸板/收盘跌停”是日线口径的超集。
5. 结论只认预登记研究：显著但方向与预登记相反（`significant_opposite_direction`）不能当作支持；未登记的探索性统计只能称为观察。
6. 信号标签收益不等于可执行收益。打板结论必须看成交模型（开盘涨停买不到、一字板排不到、跌停顺延、费用滑点），排板只有保守/乐观两种情景的范围。
7. 情绪周期阈值、题材排序、通用板块名单都是版本化工程规则，不是专家规则、题材强弱判断或交易信号。
8. Agent 没有构建数据集、抓取网页、登记或运行研究、写 Theme Matrix 的工具；这些都由宿主或收盘后调度执行。任何输出都不得变成买卖指令。
