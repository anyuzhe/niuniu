# GTJA191 provenance

- Source: https://github.com/yupoet/aurumq-rl, commit `5cf7e83637b85e4f855daec16099148b358b89b3` (2026-07-19), directories `src/aurumq_rl/factors/gtja191/` and `alpha101/_ops.py` (shared safe-division / safe-log helpers). MIT licence, Copyright (c) 2026 Paris Yu; full text in `LICENSE_AURUMQ`.
- Changes made here: import paths only (`aurumq_rl.factors.registry` -> `._registry`, `aurumq_rl.factors.alpha101._ops` -> `._alpha101_ops`); `_registry.py` is a reduced copy of upstream's registry (same ±1e6 clipping / inf->null wrapper); `__init__.py` rewritten. Factor code is otherwise byte-identical to upstream.
- Upstream itself says its formulas are translated from Daic115/alpha191 (formula only, no licence) and the Guotai Junan 2017 report "191 Alphas". About half of the functions have no paper formula string in their docstring, so for those the code *is* the specification. **These are upstream implementations, not independently verified against the paper.** Upstream flags 17 factors as `quality_flag=1` (errata-conservative: 005, 021, 033, 050, 051, 055, 062, 069, 073, 121, 131, 151, 165, 166, 181, 183, 191); they are offered with that stated in the description.
- NOT offered (see `quantlab.factors.gtja.UNSUPPORTED`, 25 of 191): 030 (upstream stub returning all-NaN), 033 and 062 (need market cap), 075 / 149 / 181 / 182 (need a real benchmark index; upstream substitutes the cross-section mean of whatever symbols are passed, which changes with the universe), 143 (recursive SELF; value depends on how much history is loaded), and 17 level-type volume/amount factors whose output sits at upstream's ±1e6 clip for a large share of values on this repo's units (volume in shares, turnover in yuan), which makes the cross-section largely constant: 011, 043, 060, 070, 081, 084, 094, 095, 097, 100, 111, 132, 134, 155, 171, 178, 180. 166 of 191 factors are offered.
- Upstream clips every output to ±1e6 and turns ±inf into null; kept, because it is part of the factor as published.
- Rolling windows count rows, not trading days: a symbol with missing (suspended) rows has longer calendar windows.
- Verification done in this repo: look-ahead audit (prefix-invariance + tamper-future) over the offered factors; see docs/reference/gtja191-integration-2026-10-15.md.
