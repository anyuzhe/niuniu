### 2026-09-17 后台自主候选实测补充

后台聊天已新增显式 `--allow-granted-research` 队列接线；缺 Grant、超范围、预算不足仍拒绝。真实 GPT-5.5 已在独立两证券样本中完成“读数据摘要 → 自拟三个DSL候选 → 预览/冻结 → 授权内提交 → 逐一读结果”；三次归档复算数值匹配，测试授权已撤销。

这是**单批次工程验收**，不是有效 Alpha 认证。每个时点只有两只股票，低于引擎的三证券 IC 门槛，Rank IC 均为空，候选有效性尚不可判断。正式工作空间的 Grant/DSL注册没有因此增加；每日唤醒模型、自主生成新提案的持久运行尚未部署。详见 [实际结果、脚本错误与证据](../archive/testing/20260917-自主因子后台实测.md)。
