# 牛牛平台 · PyQt6 原生桌面

> 历史归档（整理于 2026-09-17）：保留原阶段记录；正文中的“当前、下一步、待完成”和测试/数据数字属于原记录时点。使用与当前进度以 [文档导航](../../README.md)、[当前状态](../../project/status.md) 为准。命令仍从仓库根目录执行。

这是按 `niuniu_ui_pack` 实现的原生桌面入口。使用 PyQt6 的 QWidget、QTableWidget、QSplitter、QTabWidget、QPainter 等控件，直接调用已有研究内核，不依赖网页服务器，不使用 QWebEngineView。

## 默认研究路径

新实验默认“前复权 qfq”与“研究价格”模式；回测直接使用所选复权价格，保留手续费和滑点。默认费用入口只显示历史费用规则；选择“精细账户（不复权成交＋公司行动）”后，才启用原有公司行动配置。默认路径不需要额外的 raw 行情或分红/拆股事件。详情见 [本次验证](../../../artifacts/research-price-mode/说明.md)。

## 启动

当前工作区已安装 PyQt6，可双击 `启动牛牛平台.command`，或执行：

```sh
.venv/bin/python -m quantlab.cli desktop --output artifacts --data-root /Volumes/Lexar/niuniu-data
```

新环境先安装可选桌面依赖：`python -m pip install -e '.[desktop]'`。省略 `--data-root` 可以只读浏览、校验配置。研究产物保存在 `--output`，行情保持只读。

同一产物目录只允许一个研究执行队列；如果已有网页工作台持有执行锁，请先关闭它，或为桌面指定另一产物目录。桌面浏览不占执行锁，首次提交实验才启动队列。关闭窗口时会等待正在进行的读取和实验完成，避免丢失归档。

## 设计与功能

按设计稿保留 12 个页面名称、252 像素侧栏、顶部搜索、深海军蓝与琥珀金、牛牛图形、架构流程、卡片和表格层级，以 1920×1080 为设计基准，使用 Qt 布局管理器适配窗口。

| 页面 | 当前原生接线 |
|---|---|
| 研究工作台 | 注册统计、Theory Mapping、架构图、审计口径、近期实验 |
| 数据中心 | 数据源流程与实验来源列表；详情显示快照与股票池版本 |
| 因子库 | 原生表格检索、定义/参数检查器、关联实验、新建研究 |
| 市场状态 | 四个维度、真实条件收益热力表与明细统计 |
| 结构与事件 | 选择实验后显示原生 K 线及截至当前时点的结构事件证据 |
| 序列构建器 | 原生拖放、排序/删除、超时/失效、草稿保存载入、实际序列实验 |
| 理论实验室 | 模板选择、并列组件卡片、概念与组合规则、关联实验 |
| 实验中心 | 分页、筛选、原生表单校验和提交、任务查看、报告及子实验 |
| 组合与模型 | 组合流程、条件/评分定义及模拟账户归档；不启用 ML |
| 策略回测 | 独立成交实验、真实净值曲线、汇总指标、成交及 vn.py 核对记录 |
| 结果对比 | 同页多选 2–4 个实验，分别查看真实指标与来源口径 |
| 系统设置 | 路径、存储与引擎信息；可切换本次会话工作空间 |

原生表单覆盖现有研究方式，扩展选项使用经过已有 `prepare()` 校验的 JSON。观测数据分页读取；回放复用 `replay_page()` 的可用时间截断逻辑，并提供切换证券、定位和播放。耗时产物读取放在线程池中，切页后的过期结果不会覆盖当前页面。

这次没有把设计稿里的示例 IC、OOS 通过率、理论完成度等填成真实结果。序列编辑目前支持三种已确认事件来源上的有序/重复步骤、超时与失效；可选步骤、嵌套与跨周期序列仍未实现。未提供数据的图表不生成演示数值；部分页面以现有功能对应的原生表格/检查器呈现，并非 12 张稿件所有控件的逐像素复刻。机器学习和实盘仍不在范围内。

## 代码与验证

- `src/quantlab/desktop/app.py`：主窗口、页面和研究归档接线。

验证命令：`QT_QPA_PLATFORM=offscreen PYTHONPATH=tests .venv/bin/python -m unittest test_desktop test_workbench test_workbench_jobs -v`。

原生交互验证及截图保存在 `artifacts/pyqt-ui-acceptance/`：`native-workflow.json` 记录实际 MQC 小样本实验的表单校验、提交完成、回放前缀及切换证券检查；`pages.json` 记录 12 个入口的原生截图。截屏由运行中的 Qt 控件生成，而非设计包图片。

上一轮网页工作台代码保留，但不再作为本次桌面 UI 的交付入口。


## 原生界面第二轮（2026-09-09）

新增 `desktop/sequence_builder.py`：QGraphicsView 原生拖放与按钮排序替代操作、草稿保存/载入。编辑参数接入 `SEQ.CUSTOM_ORDERED@1.0.0`，复用 OrderedSequenceEngine；当前事件来源为前高突破、前低突破失败、前高突破失败。最多 12 步；不同时刻推进，失效优先，间隔为严格小于；规则和审计保存进正式实验归档。

理论页用真实模板组件呈现；市场状态热力表展示归档条件平均收益；系统设置可修改会话内目录（活动读取/实验期间拒绝切换，不移动任何原有文件）。K 线回放增加紫色结构点、金色事件标记、蓝色活跃区域，并沿用已知时间截断。

23 项针对性测试通过，包括原生节点拖动改变实际提交顺序、目录切换、与原序列规则等价、超时/失效及前缀因果一致性。真实 MQC 原生提交完成，审计保存 7 次 active、7 次 timeout、0 次 completed；这证明执行与审计接线成功，不代表序列盈利或产生完成信号。原生回放已验证叠加绘制及倒退后不出现未来信息。

本轮截图、测试与真实验收记录在 `artifacts/pyqt-ui-phase2/`。已打开的旧窗口不会自动载入新代码；关闭后重新运行 `启动牛牛平台.command` 使用新版本。

## 公司行动与费用模块（2026-09-10）

独立成交实验表单提供“配置公司行动与费用”：五栏事件/税费 JSON 编辑、校验和应用；本地分红/送转导入明确固定税率假设与回顾性口径，并展示来源及未解析记录。归档“公司行动与费用”页可读取完整账本，按 100 条分页并显示单条明细。真实原生操作验证 360 条流水、四页浏览、选行联动与归档复算。外盘缺失时会报告来源缺失。见 [模块验收](../../../artifacts/corporate-actions-finalization/说明与验收.md)。
