## 结论

用户提供的QQ群截图涉及pytdx返回None、跳过SetupCmd3、eltdx、北交所和财报修订日期。本轮在Mac的独立环境实际验证了数据源可达性，**不是由外部开发者代牛牛研究因子，也不是牛牛已经接通全部新源**。

eltdx返回了此前未接入的一分钟K线、指定日期成交明细、竞价过程及正式09:25撮合、五档盘口、财务/股本变迁、个股题材和历史涨跌停列表。PyPI pytdx1.72在两个主站上复现了原初始化取K线失败、跳过第三个SetupCmd后成功。仅凭这些小样本不能宣布接口长期稳定、全历史覆盖、完整QM50数据就绪或订单可成交。

## pytdx 初始化兼容性：实测而非通用补丁

两个主站116.205.183.150:7709、116.205.171.132:7709均完成A/B对照。原TdxHq_API能connect，但get_security_bars(8,0,'000001',0,5)抛TdxFunctionCallError；测试子类只保留SetupCmd1/2、不调用SetupCmd3时，两站均返回5根K线。

本轮显式启用raise_exception=True且关闭重试。官方默认raise_exception=False会把普通接口异常返回为None，故None不能直接解释为证券没数据。没有修改已安装库或全局源码，也没有凭截图行号55盲改。结论仅对应本次版本/主站/请求，不外推全部接口或其他维护分支。

## 实际数据结果

除北交所样本和涨跌停列表外，主要探测证券为sz000001。

| 数据 | 实际返回 | 范围说明 |
|---|---|---|
| 一分钟K线 | 60根，2026-09-17 14:01至15:00 | 时间有序唯一，OHLC关系及量额非负；未测全市场历史完整性 |
| 日K线 | 5根raw/none | 小范围连通与价格字段检查 |
| 历史成交明细 | 9月17日100条；另3个历史日期各20条 | 是接口分笔明细，非逐委托排队轨迹；样本时间精度为分钟 |
| 竞价过程 | 9月17日80点 | 61个开盘段点、19个收盘段点，不能混入晨间因子 |
| 正式09:25撮合 | 9月17日一条，11.68元、3624手、223笔字段 | event_kind=opening_match；非竞价过程快照 |
| 五档盘口 | 一只股票买5卖5 | 夜间查询的最近盘口，不是历史全程订单簿 |
| 财务基础快照 | 1条，含股本等，updated_date=2026-08-15 | 更新日期不等于完整财报修订版本链 |
| 股本/权息变迁 | 80条事件 | 含股本变化、除权除息；需核对类别、单位、有效日和发布时间 |
| 个股题材 | F10 error_code=0，9条 | 当前返回的题材、入选日期和原因，不是历史每日冻结成员全集 |
| 北交所 | 实际股票bj920000的3根日K线 | 已区分代码表里的指数/可转债，不把所有记录都叫股票 |

正式撮合量按手转为股后，用11.68×3624×100得到4,232,832元，这是**本地乘法推导金额**，不是接口直接返回的精确金额。旧版快照open_amount_yuan=4,232,800，depth版本为4,232,830，存在源精度/编码差异，不能默默合并成完全相等。

第一次正式撮合查询仅许可2页，报“分页达到上限但未遇到空页”，原失败保留。后续独立查询把上限明确设为8页后取到09:25记录；没有把分页截断当成不存在正式撮合。

### 不同历史日期实际能否返回

| sz000001日期 | 成交明细样本 | 竞价过程 |
|---|---:|---:|
| 2026-09-17 | 100条 | 80点 |
| 2026-09-04 | 20条 | 82点 |
| 2025-09-17 | 20条 | 72点 |
| 2024-09-04 | 20条 | 0点 |

2024日期的竞价接口正常返回空列表；它不是获取成功的非空资料。零散日期成功不证明连续250个交易日、全股票覆盖，也不能把空列表填零当成零竞价。

### 历史涨跌停与炸板列表

F10原生limit_up_down_list限定单日，不请求额外市场汇总：

- 2026-09-17：70条，供应商类型1涨停47、类型3炸板22、类型0跌停1。
- 2025-09-17：88条，类型1涨停64、类型3炸板24。

每行actual trading_date_value均与请求日期一致。返回板位、封单额、时间字段、开板次数和原因。70/88是不同类型合计，不能称70/88只涨停。该名单是供应商筛选结果，不是完整A股Universe；时间字段不能未经定义核对就映射成QM50要求的首次或最后封板时间，原因描述也不能自动作盘前事实。

## 能补哪些研究输入，哪些仍未证明

优先的新入口是1m原始K线和正式09:25量价/竞价过程；股本事件与财务快照可作为历史股本接入线索，涨跌停榜单和F10题材可用于来源对照。接入前必须保存原始响应、请求日期、实际返回日期、单位、空结果、分页完成情况和抓取时间，由牛牛检查资料覆盖并调用正式研究工具。

必须区分原生字段与Helper派生字段：daily_price_limits、latest_st等不能仅按友好名称视作官方逐日涨跌停价或历史状态证据；官方方法文档注明部分取值依靠本地规则、名称和现有快照计算。本轮未测试这些Helper，也未签发任何历史PIT资格。

财务updated_date只是该快照的更新日期。若要证明财报首次披露与每次修订后的可用值，需要报告期、首次披露时点、修订披露时点、每个版本实际字节与值的绑定；没有审计用户的QUANTAXIS财报库，因此不对其所有版本是否保留修订日期作结论。
