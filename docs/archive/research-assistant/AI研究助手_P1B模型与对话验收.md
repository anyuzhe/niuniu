没有强制所有模型使用同一协议。API 地址不允许内嵌密码、查询参数或片段；远程地址要求 HTTPS，本机回环允许 HTTP。默认拒绝 HTTP 重定向，避免将密钥转交到另一地址。

Codex 路径留空时会检查终端 PATH 和常见 nvm 安装位置，以兼容从 Finder 启动的 GUI 环境。Codex 仍请求上游云模型，不是离线推理；登录权限与额度由实际 CLI 服务决定。

## 4. 使用入口

方式一：正常重新启动牛牛，进入 **顶栏「AI 研究接口」→「打开内置研究助手」**。

方式二：在项目目录双击新增的 **`启动牛牛AI研究助手.command`**，打开原工作台及同一个内置助手入口。脚本已设置可执行权限。

展开「模型连接与预算设置」，核对当前协议、模型和推理强度。首次发送前勾选界面上的数据发送确认；改变模型或服务配置后需要重新确认。可通过「测试连接／刷新模型」取得实时模型目录，通过「保存模型配置」保存非敏感设置。

示例输入：

```text
查询 BASE.MOMENTUM 的实际定义，然后为 sh.600000、sh.600519、sz.000001
拟一份 2024-01-01 至 2024-06-30 的前复权日线研究提案：
20 根动量，1/5 根未来收益，3 分位。先预检再保存，不批准、不执行。
```

右侧显示真实工具调用、结果和引用。选择提案引用会打开原人工审批窗口，确认框不会自动勾选。用户核对批准后才进入原 JobQueue。停止助手仅停止当前模型流程，不取消此前已批准的研究任务。

## 5. 权限、凭据与恢复

工作台不读取或复制 Codex 登录令牌，不把登录状态转换为 API Key。认证由官方 CLI 自身处理。原全局配置中有旧 `agents` 字段类型不匹配；本轮采用仅对牛牛子进程生效的兼容覆盖。普通终端直接读取原配置时，原有错误仍可能存在。

专用 Codex 进程使用临时目录、只读沙箱和 `untrusted` 审批策略；关闭无关 Shell、浏览器、电脑控制、外部 MCP、插件及多智能体工具。请求额外权限或出现未开放原生动作时拒绝继续。模型侧只有既有九项查询／提案工具，没有自批、直接执行研究、任意文件路径或命令接口。

API 密钥只来自密码框或指定环境变量；保存配置不写入密钥。关闭窗口或切回 Codex 时清空密码框。对显式传入的密钥做日志隐藏；不应把密钥直接当作聊天内容输入。

会话以 `_assistant/conversations` 中的追加式记录为权威来源。新旧聊天接口共用运行层和提案服务；早期试验性 `chat.sqlite3` 可只读迁移，原数据库保留。上下文超限明确报错，不悄悄丢弃既有交流后假装仍记得。

预算包含工具次数、API 往返轮数、响应大小及请求时限。HTTP 正在进行的调用可能需返回或超时后响应停止；Codex 的输出字符／事件保护不等于精确 token 上限。没有硬内存隔离或“绝对按秒结束”的保证。
