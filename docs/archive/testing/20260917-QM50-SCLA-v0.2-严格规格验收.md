## 4. P07真实原始字段诊断

测试ID：`021fee3b-f07b-47fe-ac7a-1b0a1eb1de9e`。状态 DIAGNOSTIC_COMPLETED_NOT_STRICT。

牛牛选取：`sh.600000`、`sh.600004`、`sh.600006`、`sz.002163`、`sz.002164`。日期2026-08-01至2026-09-04，读取原始未复权日线中的实际成交额和已保存交易日历，合计125个证券/决策日。

原文公式：

```text
P07[D] = amount[D-1] / median(amount of 20 valid trading days strictly before D-1)
```

只在此前21个已知交易日都有实际正成交量、正成交额时输出原始比值。没有跳过不明缺日或零成交日，没有填零、填均值或凭极小数补分母。缺历史/缺量分别保留不可用状态，不用删行换成看似完整的结果。

本轮125行原始算术均可计算。监督复核用另一条按交易日对齐的计算路径：`amount.shift(1) / amount.shift(2).rolling_median(20)`，逐行核对125个输出和窗口边界，误差小于1e-12。该复核只检查同一已运行任务，不产生新假设、新候选或新收益研究。

示例：sh.600000的2026-08-03决策，分子为7月31日，分母为7月3日至7月30日的20个交易日；没有把7月31日混入分母。

所有行的 `historical_decision_value`、`score` 保持null，`asof_qualified=false`，严格状态MISSING_SOURCE。未验证当时可得的逐日证券状态、有效涨停价和完整昨日涨停候选池，因此这5只股票不被冒充为QM50候选池。

### D. 新发现的字段合同缺口

现有MarketRules代码包含上下限、ST/停牌、费用和有效时间，但**没有**reference_price、tick_size、board_asof、instrument_type_asof、delisting_arrangement、new_listing_no_limit_flag、normal_price_limit_regime。这是现有数据结构与QM50输入合同的差异，不是模型看到“官方规则”名称就可以推断这些字段已齐全。

基础组件因此要求证券种类、主板、正常制度、无涨跌幅新股标志等显式给出。涨停识别用原始价格和显式上下限/tick，不通过涨幅四舍五入或固定1.1推断。真实数据还缺历史bar available_at及足以结束连板前缀的事实；只检查D/D-1/D-2不能证明任意长的完整P01高度。

本轮将这些缺口连同来源入口和接受条件输出为结构化data_requests，未自行下载、回填、补签历史receipt或填入未知字段。
