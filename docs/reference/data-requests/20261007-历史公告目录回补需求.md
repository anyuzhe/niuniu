## 为什么要

抄底策略 D 含 290 只退市股后，年化从 +18.0% 降到 +15.9%，其中约 0.9 个点来自真买到了退市股（151 笔平均 +56bp，在市股平均 +283bp；2021 年起 20 笔平均 −606bp）。档案 §91–§92 已经试过用价格、成交额、回撤、估值和“按退市规则的财务条件”在买入前躲开它们，结论是躲不开：买入当天没有一笔是 ST，估值、股价、跌幅与在市股几乎一样，财务条件只命中约 6%。

剩下没有测的是**公告类风险**：立案调查、风险警示/退市风险警示预告、被问询/关注函、审计意见（保留/无法表示）、重大诉讼、重大违规、实控人变更失败等。这些信息在公告里先于退市出现，但数据湖里的 `announcements_cninfo` 只有 2026-09-17 以后，没有历史，所以无法回测。

## 需求：历史公告目录

- **范围**：全部 A 股，**包含 2006 年起退市的股票**（目前 290 只，`stock_basic` 和退市目录里有）；公告日从 2010-01-01 到 2026-09-16（和现有 `announcements_cninfo` 接上）。
- **内容**：和现有 `announcements_cninfo` 同列即可，**只要标题和时间，不要正文和 PDF**：`date, code, name, announcement_id, title, type, announcement_time_ms`。巨潮的公告类别字段（`type` 或接口里的 category）请尽量保留，后面可以用它缩小范围。
- **体量**：如果全量太大，按优先级分批：
  1. 退市股 290 只，2010 年起全部公告；
  2. 在市股里 2018 年起的“风险提示、监管函/问询函/关注函、立案、审计报告、业绩预告/修正、重大诉讼仲裁、风险警示”类公告；
  3. 其余。
- **时间标签**：写明 `date` 是巨潮的公告日（自然日）还是交易日；盘后公告在回测里按下一个交易日处理，所以需要知道是否晚于 15:00（`announcement_time_ms` 有的话最好）。
- **状态**：READY 之前 CODE 只写预先登记好的检验方案，不看结果。

## CODE 打算怎么用（预先登记，防止事后挑规则）

1. 先定关键词类别，**在看结果之前写进档案**：立案/调查通知、风险警示或退市风险警示相关、被出具保留/否定/无法表示意见的审计报告、业绩预告类型为“首亏/续亏/增亏”、问询函/关注函/监管函、重大诉讼仲裁。
2. 规则：买入信号日之前 N 个交易日（N=60、120 各一次）出现任一类别公告的股票，从候选里剔除。
3. 在含退市股面板上重跑 D 和 D1：报整体年化、夏普、回撤、被剔除的笔数、被剔除的笔数里退市股占比，并逐年列出。
4. 采用标准：年化至少提高 1 个点，且 2020 年前后两段方向一致，且被剔除的笔数不超过 15%。不满足就把“退市风险当策略成本”作为最终结论。

## CODE 的使用承诺

- 只按清单登记的路径读取；不自己扫描数据根；
- 公告标题只用于分类，不把任何一条公告当作买卖建议；
- 结果无论好坏都写进档案。
