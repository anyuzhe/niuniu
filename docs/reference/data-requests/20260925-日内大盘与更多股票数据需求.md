## 为什么要

“日内做T”研究（见[日内做T 策略研究](../../archive/intraday/20260925-日内做T策略研究.md) §12）的结论：在 `gst_intraday` 的 16 只股票上，个股自己的日内信号（突破、网格、缠论买卖点、盘口）扣费后都约等于成本；**稳定的只有大盘方向**。CODE 从 `bars_min5_baostock_raw`（READY）临时算了全市场 5 分钟数据做研究：

- 10:00 的大盘走势对当天剩余时间全市场平均走势的相关，2021–2024 年每年约 0.15–0.19；
- “上午打分”换成全市场大盘后，16 只股票 2021–2024 每年都为正（每笔扣费后 +26 到 +46 bp）；
- 在每年成交额前 500 只上，10:00 预计当天走弱的日子（每年约 8–26 天）先卖后买，每笔扣费后约 +39 到 +80 bp，当天盈利的比例约 66%。

要把它做成产品策略、并在实盘里用，需要数据侧正式提供下面的数据。

## 需求 1（最重要）：全市场日内情绪序列，历史 + 盘中

名称由数据侧定，例如 `market_intraday_breadth`。

- **粒度**：1 分钟最好；做不到就 5 分钟。每个交易日每个时点一行。
- **字段**：
  - `date, time`（按时点结束时刻标，与 `bars_min5_baostock_raw` 一致，写清楚第一根是否含开盘集合竞价）；
  - `ew_ret_prev_close`：全部 A 股等权平均“当前价 / 昨收 − 1”（昨收请按除权除息调整；CODE 临时版本用的是未复权昨收，除权日有偏差）；
  - `ew_ret_open`：等权平均“当前价 / 当日开盘价 − 1”；
  - `up_count, down_count, flat_count, limit_up_count, limit_down_count`；
  - `n_stocks`（参与计算的只数，停牌不计）；
  - 可选：成交额加权的同口径收益。
- **历史范围**：2020-01-02（5 分钟数据起点）至今；如能有 1 分钟，尽量从 2019-05 起（和 `gst_intraday` 对齐）。
- **盘中**：交易时间里每 1 或 5 分钟更新，写明数据延迟（秒）和来源；CODE 用它在 10:00、10:30 做判断。
- CODE 临时算法供核对（2020–2024 各年约 11,600 行，每时点 3,000–5,000 只）：[`scripts/research/gst_intraday_t0/market5m/breadth.py`](../../../scripts/research/gst_intraday_t0/market5m/breadth.py)。CODE 不会把这份临时结果当正式数据用。

## 需求 2：主要指数的分钟线

- 上证指数、沪深 300、中证 500、中证 1000（可加创业板指）的 1 分钟 K 线：`date, time, open, high, low, close, volume, amount`。
- 历史：2019-05 起（至少 2020-01 起）；盘中：同上写明延迟。
- 用途：和等权口径对照；学术和券商研究多用指数口径。

## 需求 3：更多股票的日内数据

- `gst_intraday` 只有 16 只，是所有日内结论的最大限制，而且其中低价股偏多（1 个价位的成本占比高）。
- 如果当初 gst 导出的来源（`stock_contracts.csv` 成交、`stock_pans.csv` 盘口所在的 MySQL）还有其他股票，请按同样的清洗和可用日规则扩展，优先流动性好、股价高于 8 元的。
- 如果没有，请告诉 CODE 是否有其他合规来源可提供 1 分钟 K 线（带主动买卖量更好），范围建议：每年成交额前 500 只，2020 年起。
- 五档盘口如果有 2020-06 之后的，也请一并提供；逐笔委托（能看到撤单、排队）如果有，价值很大。
