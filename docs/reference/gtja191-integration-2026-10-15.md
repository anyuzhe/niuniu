# GTJA191（国泰君安 191）因子包接入 — 2026-10-15

## 做了什么
- 从 `yupoet/aurumq-rl`（MIT，commit `5cf7e83637b85e4f855daec16099148b358b89b3`）移植 GTJA191 的 polars 实现到 `src/quantlab/factors/gtja191/`，只改了 import 路径；MIT 许可全文与来源说明在同目录 `LICENSE_AURUMQ`、`PROVENANCE.md`。
- 适配层 `src/quantlab/factors/gtja.py`：把牛牛的日线行情转成上游要求的面板（VWAP = 成交额/成交量×复权因子，`amount` = 成交额，`returns` = 逐股票收盘价收益），输出非有限值置空；仅日线；`quantlab.app.default_registry()` 注册为 `GTJA191Pack`。
- 因子库注册数由此从 444 增至 610（含本包 166 个；首版曾为 627，含已下线的 17 个；此前审计覆盖的 393 个之外还有 Chan 系列、COMB.*、BAO.* 等）。因子 id 形如 `GTJA191.GTJA_001`。

## 可信度（先读这个）
- **这是上游的实现，不是对论文的独立复现。** 上游自述公式转写自 Daic115/alpha191（无许可证，只借公式）与国泰君安 2017 年《191 Alphas》研报；约一半函数的文档里没有论文公式字符串，代码本身就是规格。我没有拿到研报逐条核对。
- 上游把 17 个因子标为 `quality_flag=1`（论文公式有已知勘误，保守实现）：005、021、033、050、051、055、062、069、073、121、131、151、165、166、181、183、191。其中 033、062、181 因其他原因不提供，其余 14 个提供，因子描述里已写明。
- 上游对输出做 ±1e6 截断、±inf 置空，保留（它是上游因子定义的一部分）。但这个截断对“成交量/成交额水平型”因子会把 A 股量纲整列压成常数，这类 17 个已不提供（见下）。
- 滚动窗口按行数而非交易日数：停牌缺行的股票，窗口对应的日历天数更长。

## 不提供的 25 个（`quantlab.factors.gtja.UNSUPPORTED`）
| 因子 | 原因 |
|---|---|
| 030 | 上游桩（Fama-French 暴露），输出全是 NaN |
| 033、062 | 需要流通市值，牛牛行情里没有 |
| 075、149、181、182 | 需要真实基准指数；上游用“传入股票的截面均值”代替，换一批股票结果就变 |
| 143 | 递归 SELF 定义，值取决于加载了多少历史 |
| 011、043、060、070、081、084、094、095、097、100、111、132、134、155、171、178、180（17 个） | **输出饱和**：这些是成交量/成交额的“水平型”累计或标准差，A 股量纲下大面积顶到上游 ±1e6 截断（095、132 整列恒为 1e6，100 约 80%），排名等于噪声。在 IC 扫描里发现，随后下线（`gtja.SATURATED` 记录各自的截断占比） |

## 验证
- 未来函数审计（`scripts/research/factor_causality_audit.py`，真实日线 12 只股票 × 700 个交易日，截断 + 篡改未来两种检查，3 个截点）：**183 个（当时的提供集）全部 PASS，0 处不一致**；下线 17 个后剩 166 个是其子集，未重跑，每个因子每次至少比较了 795 个值（没有空转通过）。证据不是证明；12 只股票是样本。
- `tests/test_gtja191.py`（9 个）：包只含 166 个且无重复；014/015 与手写闭式结果逐位一致；另有“提供的因子在 A 股量级数据上不顶截断”的回归测试；行序/多余列不影响结果；截面因子随传入股票变化（已知并已文档化）；VWAP 因子拒绝非法复权因子/缺失成交额；不可用输入与参数被拒绝；代表性子集无未来函数；来源声明与许可齐全且代码中无 `aurumq_rl` 残留。
