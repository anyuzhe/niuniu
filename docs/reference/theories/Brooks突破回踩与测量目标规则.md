# Brooks 突破、回踩与测量目标规则 1.0.0

> 版本化规则参考：保留原有算法合同与验证记录；本次仅调整文档位置和链接，不更改规则。命令从仓库根目录执行。[文档导航](../../README.md)

此规则包补总体方案 BrooksPack 中的 Breakout、Pullback、FailedBreakout、MeasuredMove 的一组明确 OHLC 变体。它不自动认定紧凑 TradingRange，不实现 Wedge、Climax 或 AlwaysIn，也不替代原有 H2/L2 定义。

## 起点与参数

逐证券、单周期计算，按 available_at 确认；预热 lookback 根之前输出 null，其后非事件条输出 0、事件当根输出 1。相同证券的重复 available_at 被拒绝。

- lookback：默认 20，整数 `[1,10000]`。取此前 N 根、排除当根的最高 high 和最低 low；宽度必须大于零。这是滚动价格区间，未额外要求横盘、重叠率或低波动。
- body_fraction：默认 0.5，有限数 `(0,1]`。突破条方向实体须至少占自身高低跨度该比例；跨度须大于零。
- retest_fraction：默认 0.1，有限数 `(0,1]`。回踩极值距冻结边界的绝对距离不超过原区间宽度乘该值。
- max_bars：默认 40，整数 `[1,10000]`。从突破确认起按实际观察条计数；严格超过才超时，回踩及再启动均不延长期限。

## 双向状态链

每个方向独立追踪一条活跃链；活跃链期间忽略同方向新突破，不滚动修改旧边界。向下为向上规则的价格镜像。

| 步骤 | 向上规则 | 向下规则 |
|---|---|---|
| BREAKOUT | 收盘严格高于此前区间上沿，正实体占比满足阈值 | 收盘严格低于此前区间下沿，负实体占比满足阈值 |
| PULLBACK | 后续首根 low 接近冻结上沿且收盘不低于上沿 | 后续首根 high 接近冻结下沿且收盘不高于下沿 |
| RESUMED | 后续收盘严格高于首次回踩条 high | 后续收盘严格低于首次回踩条 low |
| MEASURED_MOVE | 再启动后另一根收盘达到或超过上沿 + 原宽度 | 再启动后另一根收盘达到或低于下沿 − 原宽度 |

四个步骤必须在不同 K 线上确认。回踩条影线可以进入区间；收盘等于边界仍有效。记录首次回踩条极值后，不用后来回踩替换它。测量目标即使在突破、回踩或再启动条已越过，也不会提前完成：只在再启动之后的条检查收盘。

目标始终是边界加/减一倍原区间宽度；不以再启动价格重新测量，不是价格预测或订单止盈。极宽区间可能导致向下目标非正，此时正价格行情不可能完成该目标，链仍按失败/超时规则终止。

## 失败和终止优先级

先检查严格超过 max_bars 的超时，再判断当前阶段的失败/目标/推进：

1. 再启动之前，向上收盘低于冻结上沿、向下收盘高于冻结下沿，发布 FAILED，SequenceMatch 为 invalidated。
2. 再启动之后，向上收盘低于首次回踩条 low、向下收盘高于首次回踩条 high，发布 INVALIDATED。等于止损边界不失效；影线越界本身不触发收盘失效。
3. 再启动后未失效，收盘到达测量目标时发布 MEASURED_MOVE，链为 completed。
4. 超时发布 EXPIRED，状态为 timeout。终止当根不启动新的同方向链；样本末尾等待链保持 active。

再启动后的失效边界是回踩极值，允许收盘重新进入原区间但仍守住回踩极值。这与再启动前的 FAILED 判据有意不同。所有判定均使用收盘可用信息，不能作为盘中可成交顺序或止损成交价证明。

## 标识、研究与审计

BrooksBreakoutPack@1.0.0 新增 14 个布尔事件因子，分别为 `BROOKS.BP_` 加以下名称及 `_UP` / `_DOWN`：

`BREAKOUT`、`PULLBACK`、`RESUMED`、`MEASURED_MOVE`、`FAILED`、`INVALIDATED`、`EXPIRED`。

模板 `RESEARCH.BROOKS_BREAKOUT_PULLBACK` 同时要求 `BP_RESUMED_UP == 1` 和 20 根动量为正。理论全流程展开对应方向七个组件、动量、完整组合、共同样本消融、固定样本外、滚动和预设参数对照。逐组件移除不能消除事件内置的历史依赖，不应把消融结果称作各步骤的因果贡献。

每个事件保存相同 match_id、冻结区间及来源窗口、突破条、首次回踩条、测量目标和确认条。SequenceMatch 的 completed 表示达到测量目标；它与模板在 RESUMED 时的触发次数不同。失败、超时和末尾活跃链均保留。

事件接入已有 K 线审计回放接口，按游标 available_at 截断。本轮未新增专用目标线界面或浏览器交互。实际验证见 [验收报告](../../../artifacts/brooks-breakout-acceptance/report.md)。
