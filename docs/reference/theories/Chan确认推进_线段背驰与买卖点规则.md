# Chan 确认推进规则 1.0.0

> 版本化规则参考：保留原有算法合同与验证记录；本次仅调整文档位置和链接，不更改规则。命令从仓库根目录执行。[文档导航](../../README.md)

本规则使用已有包含处理后的确认笔，是平台自定义的保守价格结构代理。它没有实现缠论全部特征序列、缺口及不同流派的线段划分，也不用 MACD 面积或主观判图。不能将这些因子称为完整经典缠论认证。

## 确认线段

每只证券从第一根待处理确认笔的方向开始，内部维护待确认笔序列。向上段选择终点最高的同向笔，向下段选择终点最低的同向笔；同价保留首次终点。至少三笔包含在候选段内才允许确认。

候选极值之后的反向笔，必须严格突破候选极值之前最近一根反向笔的终点：向上段由更低的反向低点确认，向下段由更高的反向高点确认。确认后发布从起点到极值的线段；极值之后的笔保留为下一段待确认序列，因此相邻段在端点衔接。

候选段只在内部更新，不发布临时端点。事件 available_at 是确认反向笔的可用时间，线段真实端点时间另存 end_at；不得将信号回填至线段端点。未确认尾段不作为已完成段输出。

## 速度背驰与一类点

在新的同方向确认线段出现后，与此前最近的同方向确认线段比较：

`price_speed = abs(end_price - start_price) / start_price / observed_bar_span`

observed_bar_span 是原始已观察 K 线从起点到终点的索引差，不是自然时间，也不是合并条数。只有新段形成同方向严格新极值，且速度小于前段速度乘 divergence_ratio，才发布背驰。默认比率 0.8，合法范围 `(0,1]`，等号不触发。

下行新低且速度减弱，在向上反向笔确认线段的同一可用时点发 BUY1；上行新高且速度减弱，对称发 SELL1。反转确认已包含在线段确认中，不意味着能在极值价格成交。DIVERGENCE_UP 表示上行段速度背驰，其 Event.direction=-1；DIVERGENCE_DOWN 对应 direction=+1。

## 二类点

BUY1 后建立买入二类点等待：后续第一根下行确认笔作为回踩，其最低端点必须严格高于 BUY1 的极值。之后第一根上行确认笔必须突破回踩笔的起点才发 BUY2；没有突破就取消，不无限等待后来的成功。SELL2 对称。

任何后续笔触及或穿越一类点极值，即使尚未出现回踩，也取消等待。新同方向一类点替换旧同方向等待；买入和卖出方向分别维护。触发一类点的笔本身不作为后续回踩。

## 三类点

使用已实现的冻结中枢生命周期。当确认整笔向上离开中枢后，建立 BUY3 等待；后续第一根下行确认笔必须完全保持在中枢上沿以上，再由第一根上行确认笔突破该回踩起点。SELL3 对称，要求反弹保持在中枢下沿以下并再次向下突破。

触及中枢边界即取消等待，不算“不回中枢”。同证券新的中枢离开事件替换此前三类等待，离开笔自身不能同时充当回踩。二类、三类等待均最多允许 max_follow_strokes 根后续确认笔，默认 12；严格超过才超时。超时检查先于触边失效和成功判断。

每根确认笔先处理既有等待，再处理本根新确认线段/一类点及中枢离开产生的等待；不会用新建等待消费同一根笔。这是固定的事件优先级，不推断盘中路径。

## 输出与范围

新 Pack：ChanProgressionPack@1.0.0。因子共十个，前缀 `CHAN.RULE_`：

- SEGMENT_UP、SEGMENT_DOWN。
- DIVERGENCE_UP、DIVERGENCE_DOWN。
- BUY1、SELL1、BUY2、SELL2、BUY3、SELL3。

输出为事件发生当根的 0/1；事件审计另保存 SETUP_INVALIDATED、SETUP_EXPIRED、SETUP_SUPERSEDED，供检查为何没有等到买卖点。所有条件来自已确认笔，可与实际交易时点相隔多根原始 K 线。

继承 left/right/min_separation，默认 2/2/3，均作用于包含确认后的结构。新增 divergence_ratio 与 max_follow_strokes。旧 Chan 和 ChanInclusionPack 行为不修改。

新研究模板 `RESEARCH.CHAN_RULE_BUY2_MOMENTUM` 将 BUY2 与 20 根正动量组合，并复用组件研究、消融、固定样本外、滚动、预设参数敏感性与按可用时间截断的事件回放。这里没有交易收益、成功率或策略优劣承诺。
