# 四因子低优合成分 v1 — 原生复算结果

对象：`docs/reference/quad-factor-composite-v1.json`（c3cc544 冻结，host 侧扫描 Sharpe 1.08）。
复算日期：2026-10-14。规则：不调参；未复现则如实记录（规范 `boundaries` 要求记 `implementation_failure` 并停止）。

## 结论

**未通过。** 通过条件是同窗口、同成本下 Sharpe ≥ 1.0；原生复算 Sharpe 为 0.70（主口径，本金 1 亿），三档本金为 0.58 / 0.69 / 0.70，样本抽法换 3 种相位的理想化估计为 0.65–0.71。host 侧的 2023 年起验证段（年化 22.3%、Sharpe 0.96、最大回撤 -1.6%）同样没有复现。

## 怎么算的（全部走官方组件）

| 环节 | 用法 |
|---|---|
| 行情 | `lake/silver/qfq_kline_daily_v2` + `daily_status_v2`，2018-01-01 至 2026-09-04，共 2106 个交易日 |
| 因子 | 官方因子库 `COMB.SCORE`（原始值等权相加，不标准化）：`ALPHA101.ALPHA28`、`ALPHA158.QTLD_5`、`ALPHA158.SUMD_30`、`BASE.ATR(lookback=60)`；vnpy 4.4.0 公式 |

| 口径 | Sharpe | 年化 | 年化波动 | 最大回撤 |
|---|---|---|---|---|
| 全窗口，本金 1 亿 | **0.70** | 14.0% | 22.2% | -32.9% |
| 全窗口，本金 1000 万 | 0.69 | 13.7% | 22.2% | -33.0% |
| 全窗口，本金 100 万 | 0.58 | 10.9% | 21.9% | -33.6% |
| 满仓后（≥90% 仓位起），1 亿 | 0.73 | 15.1% | 22.7% | -29.5% |
| 2023-01-01 起（验证段），1 亿 | 0.72 | 15.0% | 23.2% | -27.6% |
| 2018–2022（选择段），1 亿 | 0.69 | 13.3% | 21.4% | -32.9% |
| 同 100 只等权基准（日再平衡） | 0.47 | 8.8% | 24.2% | -35.2% |

- 本金说明：规范没给本金。100 万本金下每个持仓槽约 1250 元、不足一手，5 元最低佣金把成本吃满（6.3 万笔小额成交，佣金 31.7 万），属本金过小的假象，所以主口径取 1 亿（事先按此理由选定，三档都已列出）。1 亿下仍有最低佣金影响，但已不是主导。
- 成交笔数：引擎成交 92,378 笔（含滚动批次的权重漂移调仓）；按批次统计的建仓笔数 40,040（每批 20 只）。总成交额约 118 倍初始资金，与「40 天换手一轮」的预期量级一致，没有异常换手。
- 逐笔：按批次逐只统计，毛收益均值 253bp（40 日，收盘退出）/ 250bp（次日开盘退出），胜率 51.8%。往返成本约 12bp（滑点 2 + 佣金 2 + 卖出税等约 8），不是 Sharpe 差距的原因；理想化估计里把成本设为 0，Sharpe 也只从 0.65 升到 0.68。
- 分年（1 亿，策略 vs 基准，单位 %）：2018 -25.4 vs -27.9；2019 +39.7 vs +33.5；2020 +23.7 vs +23.1；2021 +32.5 vs +29.0；2022 +7.1 vs -6.5；2023 +8.1 vs +7.2；2024 +15.6 vs +10.0；2025 +34.9 vs +30.1；2026 至 9 月 -2.9 vs -7.4。

- 仓位与现金（本金 1 亿）：平均仓位全期 96%、满仓后 99.8%；最低现金 4190 元，现金为负 0 天；拒单 0。
- 异常值：100 只样本日 K 中没有任何一根单日涨跌超过 25%（最大 20.2%），无除权日未处理的假信号。
- 同一条净值：全窗口、选择段、验证段、满仓后都是对引擎同一条净值曲线切片，没有换代码路径。
- **样本敏感性的适用范围**：`ideal.py`（无漂移调仓的近似估计）只在全窗口上与引擎接近（相位 0：理想化 0.65 vs 引擎 0.70）；2023 年起这一段二者不一致（理想化 0.54 vs 引擎 0.72），原因未追查。因此「换抽法 Sharpe 0.65–0.71」只对全窗口成立，不能外推到验证段；验证段结论以引擎数字为准。该差异只会让理想化偏低，不影响「未通过」的结论。

## 与 host 侧声明不一致的地方

1. Sharpe：1.08（全窗口）→ 原生 0.70；0.96（验证段）→ 0.72。
2. 熊市/震荡年超额：声明 2018 +19pp、2022 +16pp、2023 +17pp、2024 +10pp；原生为 +2.5、+13.6、+0.9、+5.6。仅 2022 接近。

5. 基准是吻合的：规范写等权基准 8.0%/0.44/-35.8%，原生 8.8%/0.47/-35.2%，说明样本池整体可比，差异出在策略这一侧。

## 与规范不完全一致的地方（必须同时看）

- **100 只名单**：规范只给了抽样规则，没存名单。原生按规则重建：池子 = qfq v2 `history_truncated=false` 且 `valid_from≤2018-01-01`，再去掉窗口内任何一天停牌或有缺失 OHLCV 的股票（沪主板 593、深主板 533、创业板 312 只），按代码排序后等距抽 34/33/33 只。等距抽法的取整方式规范没写，所以我另外用 3 种相位各抽一次做理想化估计：Sharpe 0.65 / 0.71 / 0.68，全窗口都远低于 1.0。结论对抽法不敏感，但与 host 手里的那 100 只不会完全相同。
- **退出价**：规范是「第 40 个交易日收盘」，官方引擎只支持下一根开盘成交，所以退出在次日开盘（逐笔统计里两种退出价相差 3bp，不影响结论）。
- **组合构造**：规范没写重叠批次如何合并资金。这里取每日一批、每批 1/40 的滚动目标权重，引擎按目标权重每日对齐，因此有少量漂移调仓。
- **行情入口**：官方「发布版研究行情」明确禁止用于成交模拟，所以用同一份 qfq v2 数据按研究价格模式（规范同样写的 `price_mode: research`）喂给回测，数据没有改动。
- **运行环境**：因子需要 vnpy 4.4.0 与 Python ≥ 3.11，用临时环境计算；回测引擎代码与仓库一致，未改动。

## 多重检验校正（2026-10-14 补）

host 在 1614 个单因子配置 + 2112 个两两组合 + 全部含 ALPHA28 的三/四因子组合（合计 4000+）里，按全样本 Sharpe 挑出这条候选，原规范明写“没有多重检验校正”。原生复算的 0.70 同样是**挑选之后的窗口内数字**（选择依据是 2018-01-01 至 2026-09-04 全样本，验证段 2023 起也在其中），所以也要扣除“试了多少次”。

用 `quantlab.statistics.multiple_testing`（Bailey & López de Prado 的 PSR / Deflated Sharpe）算：原生净值日收益 n=2105，日 Sharpe 0.0443（年化 0.703，与引擎 summary 一致），偏度 -0.82，峰度 9.43。未校正时 PSR(>0)=0.977，看起来显著；host 声明的 1.08 在正态假设下为 0.999。

| 等效独立试验数 N | “纯运气”能达到的年化 Sharpe 门槛 | 原生 0.70 的 DSR | host 1.08 的 DSR（假设正态） |
|---|---|---|---|
| 1 | 0.00 | 0.977 | 0.999 |
| 10 | 0.54 | 0.673 | 0.939 |
| 50 | 0.79 | 0.405 | 0.800 |
| 200 | 0.96 | 0.236 | 0.639 |
| 1000 | 1.13 | 0.115 | 0.447 |
| 4000 | 1.26 | 0.059 | 0.305 |

怎么读：
- DSR 是“真实 Sharpe 大于运气门槛”的概率，通常要 ≥0.95 才算过。原生 0.70 在 N≥10 时就已不到 0.7，host 1.08 要 N 小于约 10 才接近 0.95。
- N 是判断而不是测量：4000+ 个配置高度相关（同一因子的变体、都含 ALPHA28），等效独立数远小于 4000，但**没有保存各配置的收益序列，无法估计**；上表是敏感性范围，不是结论。
- 运气门槛用的是“零技能、独立同分布”下单个夏普估计的标准误 1/√(n-1)（年化 0.346）。若各配置夏普的真实离散更大，门槛更高（N=4000 时离散×2 则门槛 2.5，DSR 均为 0）；更小则更低（×0.5 时 host 为 0.90、原生为 0.58）。
- 所以：这个结果**不能支持“发现了稳定 alpha”**，也不能证明它是假的；按现有证据，它与“从 4000 个配置里挑出的最好运气”一致。top6 都在 1.04–1.08 是“稳定区域”的说法同样可能来自配置高度相关。

以后做类似扫描：保存每个配置的日收益序列（或至少 Sharpe、样本长度），才能估计等效独立数并做 PBO。

## 净值的抽样不确定性（2026-10-14 补）

用 `quantlab.statistics.equity_inference.bootstrap_performance`（循环块自助法，保留日收益的自相关；日收益口径与引擎 `performance_metrics` 一致）对本金 1 亿主口径的原生净值（2106 个交易日）重抽样 4000 次，块长 20 日：

| 指标 | 点估计 | 95% 区间 |
|---|---|---|
| 年化 Sharpe | 0.70 | **0.01 ~ 1.39** |
| 年化收益 | 14.0% | -2.3% ~ 32.5% |
| 最大回撤 | -32.9% | -61.3% ~ -23.1% |

- 单边检验“Sharpe 不高于 0”的自助 p 值 0.021（1000 万 0.024、100 万 0.046）；这是**未扣除搜索次数**的 p 值，与上一节的 DSR 合看，不要单独引用。
- 块长从 1 到 60 日，Sharpe 区间都在 [0.0~0.07, 1.37~1.42]，几乎不随块长变；说明这条净值的日收益自相关不强，结论不是块长选出来的。
- 分段（同样块长 20 日）：2023 年起验证段 Sharpe 0.72，区间 [-0.21, 1.75]，p=0.087；2018–2022 段 0.69，区间 [-0.22, 1.62]，p=0.076。每段只有 900–1200 个交易日，各段单独都不显著。
- 通过线 Sharpe ≥ 1.0 落在整体区间内，host 的 1.08 也在区间内：所以“未复现 1.0”的结论是**对点估计而言**——数据既没有证明真实 Sharpe 达到 1，也排除不了 1。同时 0 也只是勉强在区间外（下限 0.01）。
- 区间只衡量这一条 2106 日净值的抽样误差；不含选择偏差（见上一节）、不含未建模的冲击成本、不预测未来。
