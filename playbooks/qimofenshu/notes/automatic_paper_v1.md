# 期末50分经验量化代理：自动模拟 v1

> 历史版本，已由 [百万模拟 v2](automatic_paper_v2.md) 取代。下文10万元、单股20%、固定次日退出等限制不再适用于当前配置；保留供审计。

这是从公开经验提炼的**实验工程代理**，不是作者完整策略或已经验证有效的策略。保留原始 DRAFT 和资料，不修改过去样本；新版本 `qimo-auto-paper-v1` 也标为 DRAFT，授权后的新交易日才产生前瞻信号。板块带动性、题材核心身份、通道排队优势尚未被本版本量化。

## 固定实验规则

- 沿用现有市场情绪路由：极端风险不交易。其他状态使用工程设定的昨日恰好二连板候选池；这不是作者的固定板数规则。
- PREP 候选全集、官方逐日规则、实时 AUCTION/R1 快照都满足现有完整性门槛，才允许选择。缺失证据不得降级后开仓。
- 09:35–09:40：普通账户可达、非一字行情、涨幅为正、比竞价涨幅更强；按相对竞价增强幅度、当前涨幅、代码降序确定前一名。
- 初始虚拟资金 100,000 元，最多一只股票，目标20%，实际仓位/总敞口上限21%（含价格变化容差）。不加仓，不为维持权重反复买卖。
- 信号记录后下一个5分钟开盘尝试一次；超过信号10分钟失效。使用前一根已完成bar成交量的1%作为数量上限，100股买入单位。涨停、停牌、ST和费用使用有归档凭证的当日规则；滑点假设5bps。拒单/部分成交也不追加买入。
- 入场时同时确定次一交易日09:35退出计划；受T+1约束。跌停或停牌卖不出时延后重试，不捏造平仓。未完成退出前不接受新标的。
- 账户历史最大回撤达到5%后停止新开仓，已有退出继续。本版本没有盘中止损承诺，也没有同日止损卖出的能力。

上述数值、排序和退出政策是工程假设，不是对作者原话的复刻。

## 自动运行和结算

宿主授权配置：`artifacts/_qimo_paper/control.json`。macOS 登录任务 `com.niuniu.qimo-paper` 每30秒检查一次；电脑须登录、唤醒、联网、外置盘挂载。交易日采用供应商日历并每周刷新，不把周一至周五直接当交易日。

08:00后准备当日计划，实时窗口记录信号。18:30后自动获取该标的不复权5分钟完整行情并用既有 `DynamicPaperAccount` 结算。**不是盘口实时撮合**，盘中看到的是已记录的意图，账户成交/收益在收盘结算后更新。`available_at` 的bar收盘字段用于既有执行引擎时间约定，实际抓取时间单独归档在market文件，不能据此认证供应商历史首次可用性。

完整48根bar、来源规则或公司行动参考缺失时阻塞结算。隔夜参考前收与原始上一收盘不一致时等待公司行动处理，不将除权差额直接计为策略损益。成交使用次bar开盘流动性假设，不能代表真实排队成交或实盘容量。

状态、阻塞原因：牛牛首页 → **模拟执行 → 长期 Paper**。完成第一份合法行情交付后，独立账户 `qimo-experimental-v1` 出现在长期Paper账户统计中；此之前配置中的10万元不应被误认为已经有成交或收益。自动账户不会改写人工 Strategy Intent，也没有券商连接或模型可调用的写账户工具。

状态文件 `artifacts/_qimo_paper/status.json`；信号和结算日志 `journal.json`；独立每日编排在 `orchestrator/`；原始行情抓取在 `market/`。校验和、进程锁和账户历史前缀校验防止重启重复记账。规则变化需要新版本/账户，不能偷偷重写已提交成绩。

```bash
.venv/bin/python -m quantlab.agent.qimo_paper_cli --output artifacts --data-root /Volumes/Lexar/niuniu-data --status
.venv/bin/python -m quantlab.agent.qimo_paper_cli --output artifacts --data-root /Volumes/Lexar/niuniu-data --pause
```

`--pause` 停止新开仓，继续处理已有授权退出；不等于立即平仓。恢复通过原来源 definition 的 `--enable --source-definition-id ... --confirm`；后台安装用 `--install-agent`，单次检查用 `--tick`。

## 当前验证边界

使用合成行情检查前瞻信号入场、次日退出、T+1、涨停拒单、跌停/停牌延期、一次入场、过期信号、缺规则阻塞和重启幂等性。真实资金未接入，收益有效性未验证；当前缺少目标交易日完整Universe及逐日官方规则证据，后台启动也不等于具备实际开仓条件。前瞻模拟样本须从后续真实运行积累，不能用这些合成测试冒充样本外业绩。
